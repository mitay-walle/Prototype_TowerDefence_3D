## Level generation seed and road geometry fix

- Root cause 1: `LevelTileGenerationProfile.IsRoadCell` mapped the west and east horizontal cells to the opposite connection flags. Runtime tile logic was valid, but turn and junction meshes were mirrored horizontally, so road edges did not visually meet.
- Root cause 2: `LevelGenerator` had no generation seed and `MapGenerator` consumed the shared Unity RNG state. Repeated generation could therefore replay the same layout.
- `LevelGenerator.seed = 0` now creates a new seed for every `GenerateLevel` call; a non-zero seed remains deterministic. `MapGenerator` uses a local `System.Random` stream.
- `GenerateLevel` clears existing non-base tile instances before placing the new seeded layout, so the new seed is visible when the command is repeated. `ReloadLevel` delegates to that idempotent path.
- Verification: explicit seed smoke returned `sameSeedEqual=True`, `differentSeedChanged=True`, `edgeMismatches=0`; Play Mode repeated generation returned different seeds and layouts with 11 tiles; `TD.Tests.MapGeneratorTests.TestMapGeneration_SeedControlsLayout` passed.
