- `tools/scene-gameobject.md`: scene, GameObject, and component tools.
- `tools/script-assets-materials.md`: script, asset, prefab, material, and texture tools.

- `tools/camera-graphics-packages.md`: camera, graphics, rendering, package tools.
- `tools/physics-probuilder-profiler-docs.md`: physics, ProBuilder, profiler, reflection, and docs tools.

For Unity test authoring and test execution workflow, use `$test-writing`; this reference only preserves exact MCP test tool parameters.
