# Unity MCP Workflows Index

Open only the topic file needed for the current task:

- `workflows/overview.md`: setup, routing checks, and operation prerequisites.
- `workflows/scene-and-script.md`: scene generation, scene creation, script creation, and script edits.
- `workflows/assets-debugging.md`: asset workflows, testing redirect to `$test-writing`, and debugging patterns.
- `workflows/ui-input.md`: UI Toolkit, uGUI, RectTransform, EventSystem, and input-system workflows.
- `workflows/camera-graphics-probuilder.md`: camera, Cinemachine, ProBuilder, graphics, rendering, and light baking.
- `workflows/package-api-batch-error.md`: package management prohibitions, API verification, batch operations, and error recovery.

Do not load all workflow references at once unless the task explicitly spans multiple domains.
