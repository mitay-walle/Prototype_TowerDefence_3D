# KISS

KISS is a widely used programming principle, usually expanded as "Keep It Simple, Stupid." It means preferring the simplest design that correctly satisfies the current requirements and avoiding unnecessary complexity.

## Principles

- Solve the stated problem, not hypothetical future variants.
- Prefer clear control flow, familiar language features, and direct data flow.
- Keep interfaces, dependencies, configuration, and abstractions no larger than the current requirements need.
- Do not add indirection or generalization until real duplication or a current requirement justifies it.
- Do not confuse simplicity with fewer lines: readable, testable, maintainable code is the goal.
- Do not sacrifice correctness, security, required performance, error handling, or required extensibility for superficial brevity.
- Reassess the design when requirements change; a solution is simple when its complexity is justified by the problem it solves.
